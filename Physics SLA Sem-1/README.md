# Physics SLA Sem-1: Metrology and Indian Knowledge Systems (IKS)

An interactive, high-fidelity metrology simulation suite built with Vanilla HTML, CSS, and Javascript. 

## Features
- **Vernier Caliper**: Full 2D model with dynamic sliding scale, zero-error calibration, custom test objects tray, interactive zooming, drag-to-pan viewport, and an animated portrait depth-mode.
- **Screw Gauge**: Fully functional micrometer simulator showing circular scale divisions, pitch scale readings, and calibration errors.
- **Spherometer**: Surface curvature calculator supporting flat, convex, and concave measurements.
- **IKS Metrology**: A specialized section highlighting traditional Indian measurement units (Sutra, Angula, Hasta) mapped to standard modern metric equivalents.
